# QueueLess

QueueLess helps students check how busy a campus place is before walking there, using recent student reports and past crowd patterns.

A Kappa Theta Pi pledge project at UT Dallas. Final demo: December 3, 2026.

## Team board
[Open the QueueLess project board](https://github.com/users/Mxs8513/projects/3) to track tasks and post progress updates. All Week 1 tasks are due October 9, 2026.

Move your task through **Todo → In Progress → In Review → Done**. Add issue comments with what is done, what is next, and blockers. Open a pull request with `Closes #<issue-number>` and request one review. Move to Done when the acceptance criteria are met and the PR is merged.

## Stack
- Expo (managed workflow), React Native, and TypeScript
- Expo Router for navigation
- Firebase Firestore and Anonymous Auth; Cloud Functions only if needed
- Optional data/ML: Python, pandas, and scikit-learn
